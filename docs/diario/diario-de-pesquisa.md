# Diário de pesquisa

Uma nota por dia de trabalho, no formato `AAAA-MM-DD.md`, criada pelo comando de nota
diária do Obsidian (já configurado) a partir do [modelo de diário](../modelos/diario.md).

Volta para o [índice da documentação](../mapa-da-pesquisa.md).

## Para que serve

Na escrita do [relatório final](../../relatorio/mapa-do-relatorio.md), a justificativa de cada
escolha já está registrada com data: o que rodou, o que deu errado e por que se decidiu
assim. É o registro que nenhum resultado salvo em `reports/` guarda.
