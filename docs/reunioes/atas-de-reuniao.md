## Como escrever uma ata que ajuda o grafo

Cada ata deve **apontar para as coisas que ela decide**, e não só descrevê-las. É isso que
liga a ata ao resto do cofre:

- o que foi discutido: link para a seção de [resultados](../resultados.md) ou para o
  notebook em questão;
- o que foi decidido: link para o [cronograma](../cronograma.md), para
  [`configs/`](../../configs/parametros-dos-experimentos.md) ou para o arquivo que mudou;
- o que ficou para fazer: itens `- [ ]`, que aparecem juntos em qualquer nota com uma
  consulta do plugin Tasks (ver [obsidian](../obsidian.md));
- o que foi lido ou indicado: link para a nota da leitura em
  [`docs/leituras/`](../leituras/mapa-das-leituras.md).

**LGPD** nas atas: além do autor e do orientador, não nomeie outras pessoas, e nada de
dado pessoal real (ver [CLAUDE.md](../../CLAUDE.md)).
