# 1. Dados

Resultados desta etapa da pesquisa: gerar a rede sintética, importar dados externos, conferir o gabarito e comparar o gerador com o Pix real (BCB).

Ficam em [`results/`](results/) (tabelas) e [`figures/`](figures/) (figuras), gravados pelos scripts de [`scripts/01_dados/`](../../scripts/01_dados/README.md). O que cada arquivo contém está no [mapa dos resultados](../mapa-dos-resultados.md#1-dados-01_dados); a interpretação, em [resultados](../../docs/resultados.md).
