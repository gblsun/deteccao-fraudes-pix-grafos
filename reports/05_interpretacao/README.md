# 5. Interpretação

Resultados desta etapa da pesquisa: entender os erros dos modelos: quem são os falsos positivos e o que os leva ao topo do risco.

Ficam em `results/` (tabelas) e `figures/` (figuras), quando gerados, gravados pelos scripts de [`scripts/05_interpretacao/`](../../scripts/05_interpretacao/README.md). O que cada arquivo contém está no [mapa dos resultados](../mapa-dos-resultados.md#5-interpretação-05_interpretacao); a interpretação, em [resultados](../../docs/resultados.md).
