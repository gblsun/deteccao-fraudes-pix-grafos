# Ferramentas

Scripts desta etapa da pesquisa: busca, grafo de notas, ilustrações, figuras didáticas dos testes e o relatório.

- [`gerar_ilustracoes.py`](gerar_ilustracoes.py): figuras explicativas do README: padrões, GIF da quadrilha e recorte da rede
- [`ilustrar_testes.py`](ilustrar_testes.py): figuras didáticas dos testes: estatística sob H₀ com a zona crítica e os dados contra a normal
- [`exportar_grafo_de_notas.py`](exportar_grafo_de_notas.py): grafo de notas do Obsidian em JSON, para agentes de IA
- [`buscar.py`](buscar.py): busca única no código (Graphify) e no texto de todas as notas, sem acentos nem LLM
- [`ilustrar_grafos_de_conhecimento.py`](ilustrar_grafos_de_conhecimento.py): figuras do README: grafo de notas (cores do Obsidian) e mapa do código (Graphify)

Os resultados vão para [`reports/ilustracoes/`](../../reports/ilustracoes/README.md). O que cada script lê e grava está no [mapa dos scripts](../mapa-dos-scripts.md#ferramentas); a ordem das etapas, no [fluxo da pesquisa](../../docs/fluxo-da-pesquisa.md).
