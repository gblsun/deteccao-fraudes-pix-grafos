# 5. Interpretação

Scripts desta etapa da pesquisa: entender os erros dos modelos: quem são os falsos positivos e o que os leva ao topo do risco.

- [`investigar_falsos_positivos.py`](investigar_falsos_positivos.py): quem são as contas de maior risco que não são fraude, e por que chegam ao topo

Os resultados vão para [`reports/05_interpretacao/`](../../reports/05_interpretacao/README.md). O que cada script lê e grava está no [mapa dos scripts](../mapa-dos-scripts.md#5-interpretação); a ordem das etapas, no [fluxo da pesquisa](../../docs/fluxo-da-pesquisa.md).
